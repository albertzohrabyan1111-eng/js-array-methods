# JS Զանգվածի Մեթոդներ (JavaScript Array Methods Interactive Guide)

Ինտերակտիվ ուսուցողական վեբ-հավելված JavaScript լեզվի զանգվածների (Arrays) մեթոդները սովորելու, փորձարկելու և համեմատելու համար։

## 🚀 Ֆունկցիոնալություն

- **Մեթոդների ուսումնասիրություն**. Զանգվածի 43 մեթոդների մանրամասն նկարագրություն, Visual stage (հիշողության բջիջների տեսողական պատկերում)։
- **Գուշակիր արդյունքը (Quiz)**. Թեստավորիր գիտելիքներդ՝ գուշակելով մեթոդի վերադարձրած արժեքը։
- **Ինտերակտիվ կոդի խմբագրիչ (Playground)**. Փոխիր կոդը անմիջապես զննարկիչում (browser) և տես արդյունքը։
- **Մեթոդների համեմատում (Compare mode)**. Տես նմանատիպ մեթոդների (օր․՝ `.find()` vs `.findIndex()`, `.sort()` vs `.toSorted()`) տարբերությունները կողք-կողքի։
- **Առաջադիմության պահպանում**. Սովորած մեթոդները նշվում են և պահպանվում `localStorage`-ում։

## 📁 Ֆայլերի կառուցվածքը

- `index.html` — Հավելվածի հիմնական HTML կառուցվածքը։
- `style.css` — Հիմնական դիզայնի, գույների, թեմաների (light/dark) և էլեմենտների ոճերը։
- `responsive.css` — Ադապտիվ (responsive) ոճեր փոքր էկրանների և պլանշետների համար։
- `script.js` — Հավելվածի ամբողջ տրամաբանությունը, ինտերակտիվությունը, մեթոդների տվյալները և կոդի աշխատեցումը։
